Music-captioning model

Python  ·  machine learning  ·  team project

Trained on Google’s MusicCaps dataset, it takes features pulled from a music clip and writes a short text description of it. We wrote the algorithm ourselves instead of leaning on a high-level library, so we dealt with the whole pipeline: data prep, training, and checking how well it did.

It isn’t finished. The pipeline runs end to end — architecture, training loop, evaluation — but training runs were far too slow on the hardware we had, so the model is under-trained rather than done. The interesting part, building it from the ground up, is all there.
