Flight-school platform

Next.js  ·  Supabase  ·  Stripe  ·  in progress

This one is a system for running a small flight school. Scheduling, the syllabus and lessons, dispatching airplanes, a digital logbook the instructor signs, a risk check before every flight, and billing, all in one place. Most schools do this with paper, a few spreadsheets, and whatever calendar they already use, and how good your training is comes down a lot to which instructor you get.

I want to change that. Every student on the same real syllabus, and records that actually hold up later. It comes out of my own time instructing and dispatching. Not live yet, but soon.

Music-captioning model

Python  ·  machine learning  ·  team project

A group project. It takes a short clip of music and tries to write a sentence describing it, trained on Google’s MusicCaps dataset. We didn’t use a machine learning library for the core of it, we wrote the algorithm ourselves, so we handled the whole thing. Cleaning the data, training, testing how it did.

It isn’t finished. The pipeline runs, but training was really slow on the computers we had, so the model never got trained as far as it needed to. The hard part was building it from scratch, and that part works.
